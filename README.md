# 末日快递驿站

AstrBot `aiocqhttp`（NapCat / OneBot v11）QQ群插件。副本按群独立存档：一局有严格 1200 个文字包裹，随机抽出后立即从卡池移除；抽光时自动进入下一局。

## 安装

1. 将整个 `astrbot_plugin_zombie_station` 文件夹放入 AstrBot 的插件目录，或在 WebUI 上传其 ZIP 包。
2. 确认 AstrBot 版本至少为 `4.24.2`，并启用 `aiocqhttp` QQ 平台。
3. 在插件设置中按需设置 `daily_stamina`，它是未单独设置玩家的默认每日体力，默认是 10。
4. 打开插件详情页的 **末日快递驿站** 页面，上传你的 1200 行卡牌表。上传会清空全部正在进行的群局，避免旧抽取记录与新卡池混用。

## 为什么会抽到“未登记包裹”

这不是随机抽取出错。出现“未登记包裹 0982”及“请在 WebUI 导入你的 1200 行卡牌表后开始正式副本。”，说明当前卡池来源仍是 **内置占位卡池**：正式卡牌表还没有成功导入，或导入后又被插件恢复为默认状态。

在插件 Pages 顶部查看“卡池来源”：

- 显示 `内置占位卡池`：尚未导入成功，群内抽到的一定是占位文字。
- 显示你的文件名，例如 `快递驿站卡池.xlsx`：已经在使用该文件的正式卡牌。

导入正式表格会**清空全部正在进行的群局**，所以你截图中的第 4 局会被移除。导入成功后，在群里重新发送 `驿站 开局`，才会从第 1 局使用正式卡牌开始。

## 卡牌表格式

### 文件要求

| 项目 | 要求 |
| --- | --- |
| 文件类型 | UTF-8 编码的 `.csv`，或 `.xlsx` 工作簿。 |
| Excel 工作表 | 只读取**第一个工作表**；请把 1200 张正式卡放在第一个表。 |
| 文件大小 | 不超过 5 MB。 |
| 卡牌数量 | **有效卡牌必须恰好 1200 张**。第一行表头不计入 1200 张。 |
| 空行 | 完全为空的行会被忽略，不算卡牌。 |
| 纯文字 | 名称和内容会原样作为 QQ 纯文本发送；不要依赖图片、HTML 或 Markdown 渲染。 |

### 推荐的两列表头

最推荐直接使用以下两列，列顺序可以互换：

| 名称 | 内容 |
| --- | --- |
| 医疗箱 | 获得基础治疗物资。 |
| 沾血的收据 | 记录着一个尚未搜查的地址。 |
| 封死的保温箱 | 里面传来微弱的抓挠声。 |

- **名称**：开包结果的标题，会显示为 `1. 医疗箱`。
- **内容**：标题下一行的剧情、物品、事件或效果文本。
- 每个数据行就是一个包裹；第 2 行至第 1201 行应当各有一张有效卡牌。
- 同名或同内容的卡牌允许存在；它们仍按不同包裹参与不放回随机抽取。

CSV 可以按以下格式保存：

```csv
名称,内容
医疗箱,"获得基础治疗物资。"
沾血的收据,"记录着一个尚未搜查的地址。"
封死的保温箱,"里面传来微弱的抓挠声。"
```

如果内容含有英文逗号、换行或双引号，请让 Excel 正常导出 CSV，或直接使用 XLSX，避免手工 CSV 转义出错。

### 可识别的列名

插件会忽略大小写并识别下列列名。建议优先用上面的 `名称` 与 `内容`，以免误读。

| 字段 | 可用列名 |
| --- | --- |
| 标题 | `名称`、`标题`、`卡牌`、`name`、`title` |
| 正文 | `内容`、`描述`、`效果`、`text`、`description` |

规则如下：

1. 一行只要标题或正文至少有一个非空，就算一张有效卡牌。
2. 标题为空、正文不为空时，插件自动生成 `包裹 0001` 之类的标题。
3. 正文为空、标题不为空时，可以导入，但 QQ 里只会显示标题。
4. 不需要填写编号、稀有度、图片地址等列；额外列会被忽略。
5. 若有效卡牌不是 1200 张，导入会失败，旧卡池和群局不会被替换。

### 导入步骤

1. 复制 `card-template.csv`，或用 Excel 新建第一个工作表并填入表头 `名称`、`内容`。
2. 填完**恰好 1200 行**正式卡牌后，保存为 UTF-8 CSV 或 XLSX。
3. 打开 AstrBot WebUI → 插件 → **末日快递驿站** → Pages 页面。
4. 在“导入卡牌表”选择文件，点击“导入并重置群局”。
5. 确认页面的“卡池来源”显示上传文件名，再回到 QQ 群发送 `驿站 开局`。

> 导入成功后，如果仍看到“未登记包裹”，请刷新插件 Pages 确认卡池来源；若来源是文件名，请重载 AstrBot 插件后再试。

## 群内流程

| 指令 | 权限 | 作用 |
| --- | --- | --- |
| `驿站 开局` | 群成员 | 创建副本，发起者成为主持人。 |
| `驿站 开包 [1-10]` | 群成员 | 消耗等量体力开包；省略数量时开 10 个。 |
| `驿站 新一天` | 本局主持人 | 天数加一，并按每名玩家的每日上限恢复体力。 |
| `驿站 设体力 <QQ号> <数值>` | 本局主持人 | 设置指定玩家的每日体力上限，并立即同步当前体力。 |
| `驿站 状态` | 群成员 | 查看本局进度、当前体力和每日上限。 |
| `驿站 帮助` | 群成员 | 显示指令。 |
| `驿站 管理重置` | AstrBot 管理员 | 强制开下一局。 |
| `驿站 管理设体力 <QQ号> <数值>` | AstrBot 管理员 | 强制设置指定玩家的每日体力上限。 |
| `驿站 管理状态` | AstrBot 管理员 | 查看本群统计摘要。 |

每次开包最多 10 个，抽取不放回。最后一个包裹被抽出时，聊天消息先展示该次结果，然后自动建立下一局（第 1 天、满 1200 包、玩家体力记录重置）。

## WebUI

`pages/dashboard/` 是 AstrBot Plugin Pages：页面显示卡池来源、进行中群局、每局剩余包数和所有玩家的累计/当日开包数及体力。可直接调整已入局玩家的每日体力，或输入 QQ 号提前录入体力上限。它只通过 AstrBot 注入的 `window.AstrBotPluginPage` Bridge 调用插件本地接口，不使用图片或外部前端依赖。

请仅向可信的 AstrBot Dashboard 管理者开放 WebUI；导入接口会替换全局卡池。
